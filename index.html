怎么用

  1. 司机打开 App，连上一个点歌台服务器：用朋友给的邀请码，或者自己搭一个。
  2. 在「设置 → QQ 音乐登录」里用你自己的 QQ 扫码登录。会员歌曲需要你的账号本身有会员。
  3. 点「开始播放」。手机连上 CarPlay 或蓝牙后，声音自动走车机；锁屏、切到导航也不停。
  4. 点右下角的二维码，朋友用手机相机扫一下就能搜歌、点歌，不用装 App，安卓手机也行。
  5. 点的歌按顺序排队。没人点歌时，从兜底歌单里随机放；兜底歌单可以换成你从任何音乐 App 导入的歌单。

用邀请码开一辆车

如果有朋友自己搭了点歌台服务器，可以请他给你一个邀请码：

  1. 打开 App，选「我有邀请码」，粘贴朋友发来的邀请（整段文字也行）。
  2. 给你的车起个名字，点「开一辆车」。
  3. 按提示用你自己的 QQ 扫码登录 QQ 音乐。

这辆车的数据（队列、朋友的昵称、你的 QQ 音乐登录）存在朋友的服务器上，由他负责保管。你随时可以在「设置 → 我的车」里退出 QQ 音乐登录，或者删除这辆车，删除后服务器上的数据全部清掉。

自己搭服务器（约 15 分钟）

不需要电脑，也不需要会编程，全程在手机或电脑的浏览器里完成。

1. 买一台云服务器

  • 阿里云或腾讯云的「轻量应用服务器」，最低配置就够（2 核 2G）。
  • 地域选中国大陆（离你近的城市）。QQ 音乐按服务器所在地判断版权，放在海外很多歌放不了。
  • 系统镜像选 Ubuntu 22.04 或 24.04。

2. 放行端口

在服务器控制台的「防火墙」（或「安全组」）里，添加规则放行 TCP 80 和 TCP 443。

443 是 https；80 只在申请、续期 https 证书时用。

3. 一键安装

在控制台点「远程连接」（阿里云叫 Workbench，腾讯云叫 OrcaTerm），打开网页终端，粘贴下面这行，回车：

curl -fsSL https://39.108.51.5/install.sh | sudo bash

等几分钟。它会装好运行环境、申请 https 证书（Let's Encrypt，自动续期）、设置开机自启，最后打印两行：

  • 播放器链接（https://你的IP/player?k=…）：只给你自己用，别发给别人；
  • 点歌链接：朋友用的，App 里的二维码就是它。

以后想更新到新版本，再运行一次同样的命令就行，你的队列、设置和登录都会保留。

4. 连上 App

  1. 复制播放器链接，打开 App，选「我有播放器链接」，粘贴、保存。
  2. 「设置 → QQ 音乐登录」，用你自己的 QQ 扫码。
  3. 完成。让朋友扫码点歌吧。

常见问题

有的歌放不了 / 一直跳过

大多是会员歌曲而登录的账号没有会员，或者 QQ 音乐的登录过期了。在「设置 → QQ 音乐登录」重新扫码。服务器在海外时很多歌也放不了。

朋友扫码打不开

检查服务器防火墙是否放行了 443 端口；确认服务器的 https 证书还有效（App 首页会在证书快过期时提醒）。

锁屏或切到导航后不放了

在「设置」里打开「队列空时保持后台在线」。车上建议手机连着充电。

换手机 / 删掉 App 重装

重新粘贴播放器链接即可，队列和设置都在服务器上。用邀请码开的车，可以先在「设置 → 我的车」里备份播放器链接。

怎么卸载服务器

在服务器上运行 sudo systemctl disable --now car-jukebox，再删掉 /opt/car-jukebox；或者直接释放这台云服务器。
